# NetDCA_v2

Сеточные торговые роботы для QUIK на Python 3.13. Каждый робот работает отдельным
процессом со своими настройками и состоянием; общий Python-шлюз использует одно
Lua-подключение к терминалу. Количество роботов не ограничено четырьмя.

## Подготовка после клонирования

Из папки проекта в PowerShell:

```powershell
py -3.13 -m venv env
1..4 | ForEach-Object { Copy-Item "settings_$_.example.py" "settings_$_.py" }
```

В каждом `settings_N.py` указать класс, инструмент, рабочую ногу, счёт и параметры
сетки, затем установить `CONFIGURED = True`. Рабочие настройки исключены из Git.
Шаблоны содержат параметры демо-инструментов последнего тестирования; перед
использованием сверить их с подключённым QUIK. Порты и BOT_ID выбираются по номеру
файла. Новому роботу нужны `bot_N.py`, `settings_N.py` и `start_bot_N.bat`.

Запустить `QuikPy/QUIK/lua/QuikSharp.lua` в QUIK с сохранением зависимостей Lua
и `QuikPy/QUIK/socket/core.dll`. Затем запускать ботов двойным щелчком по
`start_bot_N.bat`; общий шлюз запускается автоматически в фоне.

Исполняемый код не различает демо и реальный терминал. После загрузки Lua сначала
проверить настройки через `env\Scripts\python.exe -B -X utf8 bot_1.py --check`.

`runtime/`, реальные настройки, журналы, база заявок, состояния и окружение Python
хранятся только локально. Исходники Python, Lua-коннектор и `core.dll` включены.
Отсутствующее состояние при запуске означает выбор текущей цены как базовой;
позиции и заявки в QUIK при этом не обнуляются.

## Локальные проверки

После подготовки файлов настроек:

```powershell
& '.\env\Scripts\python.exe' -m pip install -r requirements-dev.txt
& '.\env\Scripts\python.exe' -B -X utf8 -m unittest discover -s tests -v
```

Часть сравнительных тестов в `tests/test_audit.py` использует соседнюю исходную
копию `../NetDCA/main.py`. `tools/verify_source.py` также предназначен для исходного
локального рабочего места с `source_manifest.json` и каталогом `../NetDCA`.
Остальные тесты используют имитатор, торговые заявки в QUIK не отправляют.
Последний полный локальный прогон: 109 тестов успешно. Длительная приёмка финальной
версии в демо-терминале ещё не завершена; локальные тесты её не заменяют.
